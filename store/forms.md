## App content → Data safety
- Does your app collect or share any of the required user data types? **No**
- (If asked) Is all user data encrypted in transit? Not applicable: no user data is sent. The game is served over HTTPS.
- (If asked) Do you provide a way for users to request that their data is deleted? Not applicable: no data is collected. Progress lives only on the device and is removed by clearing storage or uninstalling.

Result shown on the store: "No data collected" and "No data shared with third parties".

Why "no" is correct: progress is stored only in on-device local storage and never sent anywhere. The game's server requests (GitHub Pages, cdnjs, Google Fonts) only load the game's own files; Google's form doesn't count data that is used only to serve the app and isn't collected by the developer.
